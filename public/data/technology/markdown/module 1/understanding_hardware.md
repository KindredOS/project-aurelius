## What is Hardware?

\[Prompt Wrap Start]
What do you think hardware is, and how is it different from software?
\[Prompt Wrap End]

Hardware is the physical parts of a computer system—things you can touch and see. This includes devices like the keyboard, screen, mouse, and the internal parts like the processor and memory. Hardware works with software to make a computer function. Without hardware, software has nothing to run on!

## Types of Hardware

\[Prompt Wrap Start]
Can you name the different types of input and output devices?
\[Prompt Wrap End]

Hardware can be divided into input devices (like keyboards, mice, and cameras), output devices (like screens and printers), and internal components (like the CPU and hard drive). Each piece plays a role in how you interact with your computer.

## Inside a Computer

\[Prompt Wrap Start]
What do you think the motherboard and CPU do inside a computer?
\[Prompt Wrap End]

Inside the computer, the motherboard connects all the parts together, and the CPU (Central Processing Unit) is like the brain—it processes information and makes decisions. Memory (RAM) stores temporary data, and storage (like hard drives or SSDs) keeps your files and programs safe.

## How Hardware and Software Work Together

\[Prompt Wrap Start]
What would happen if a computer had hardware but no software?
\[Prompt Wrap End]

Hardware and software need each other. Hardware is the machine, but software tells it what to do. For example, a video game (software) needs a computer, controller, and screen (hardware) to run. When both work together, amazing things happen.
