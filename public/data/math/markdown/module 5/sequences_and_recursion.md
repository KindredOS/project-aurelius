## What Are Sequences?

[Prompt Wrap Start]  
This section introduces sequences as ordered lists of numbers.  
Prompt: How is a sequence different from just a random set of numbers?  
[Prompt Wrap End]

A **sequence** is an ordered list that follows a rule.  
- Example: 2, 4, 6, 8… (add 2 each time).  
- Example: 1, 2, 4, 8, 16… (multiply by 2 each time).  

Sequences are patterns that help us predict what comes next.

## Arithmetic Sequences

[Prompt Wrap Start]  
This section explains arithmetic sequences.  
Prompt: What’s the rule for 5, 8, 11, 14…?  
[Prompt Wrap End]

In an **arithmetic sequence**, each term is found by adding the same number.  
- Formula: aₙ = a₁ + (n – 1)d  
- Example: First term a₁ = 5, common difference d = 3 → aₙ = 5 + (n – 1)3.  

These sequences grow by constant steps.

## Geometric Sequences

[Prompt Wrap Start]  
This section introduces geometric sequences.  
Prompt: What’s the rule for 3, 6, 12, 24…?  
[Prompt Wrap End]

In a **geometric sequence**, each term is found by multiplying by the same factor.  
- Formula: aₙ = a₁ × rⁿ⁻¹  
- Example: First term a₁ = 3, ratio r = 2 → aₙ = 3 × 2ⁿ⁻¹.  

These sequences grow (or shrink) by multiplication.

## What Is Recursion?

[Prompt Wrap Start]  
This section introduces recursion as building from previous terms.  
Prompt: How could you find the 10th term if you only know the one before it?  
[Prompt Wrap End]

A **recursive rule** defines each term using earlier terms.  
- Example: Fibonacci sequence → a₁ = 1, a₂ = 1, aₙ = aₙ₋₁ + aₙ₋₂.  
Recursion focuses on relationships between terms rather than a single formula.

## Recursive vs. Explicit Formulas

[Prompt Wrap Start]  
This section compares the two ways of describing sequences.  
Prompt: Which is easier—knowing a formula for the nth term, or building it step by step?  
[Prompt Wrap End]

- **Explicit formulas**: give a direct rule for any term (fast to calculate).  
- **Recursive rules**: build term by term (good for algorithms or coding).  

Both approaches are powerful, depending on the problem.
