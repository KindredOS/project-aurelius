## Infinity, Paradoxes, and Set Theory

---

### What Is Infinity?

[Prompt Wrap Start]  
This section introduces infinity as a concept beyond counting.  
Prompt: If you keep counting forever, what does that mean for numbers?  
[Prompt Wrap End]

**Infinity** is not a number but an idea—something without end.  
- The natural numbers 1, 2, 3… go on forever.  
- Infinity appears in math, science, and philosophy as a way to describe the limitless.

### Paradoxes of Infinity

[Prompt Wrap Start]  
This section explains how infinity leads to surprising results.  
Prompt: How can a hotel with infinitely many rooms still be “full” but also fit more guests?  
[Prompt Wrap End]

Infinity creates paradoxes:  
- **Hilbert’s Hotel**: a fully occupied infinite hotel can still add new guests by shifting everyone over.  
- **Zeno’s Paradoxes**: motion seems impossible if you keep dividing space and time.  

Paradoxes stretch our understanding of what infinity means.

### Set Theory Basics

[Prompt Wrap Start]  
This section introduces sets as collections of objects.  
Prompt: What’s an example of a set in your everyday life?  
[Prompt Wrap End]

A **set** is a collection of elements.  
- Example: {apples, bananas, cherries}.  
- Sets can be finite (days of the week) or infinite (whole numbers).  

Set theory provides the foundation for modern mathematics.

### Different Sizes of Infinity

[Prompt Wrap Start]  
This section explains countable and uncountable infinities.  
Prompt: How can some infinities be “bigger” than others?  
[Prompt Wrap End]

- **Countable infinity**: numbers you can list one by one (integers).  
- **Uncountable infinity**: numbers like real decimals, too many to list.  
Georg Cantor showed that infinities come in different sizes, revolutionizing math.
