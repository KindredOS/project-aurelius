## Introduction to Programming Languages

\[Prompt Wrap Start]
Have you ever wondered how computers understand what we tell them to do?
\[Prompt Wrap End]

Programming languages are how we talk to computers. They use special rules and words to give instructions. Just like we have many human languages, there are many programming languages—each with its own style and purpose. Learning one helps you create software, apps, and even games.

## What is a Programming Language?

\[Prompt Wrap Start]
What do you think a programming language looks like?
\[Prompt Wrap End]

A programming language is a way to write code that computers can follow. It tells the computer what to do step by step. Some languages look more like English, while others use symbols and short commands. Examples include Python, JavaScript, and Scratch.

\[interactive element]

## Why Do We Need So Many Languages?

\[Prompt Wrap Start]
Why do you think there are different languages for programming?
\[Prompt Wrap End]

Different programming languages are better at different things. Some are great for building websites, others for making games or running robots. Just like tools in a toolbox, each language is good for certain tasks.

## Block-Based vs. Text-Based Languages

\[Prompt Wrap Start]
Which sounds easier to you: snapping together blocks or typing out instructions?
\[Prompt Wrap End]

Block-based languages like Scratch let you build programs by dragging and connecting blocks—perfect for beginners. Text-based languages like Python involve writing code with a keyboard. Both teach how to think like a programmer.

## Popular Programming Languages

\[Prompt Wrap Start]
Have you heard of any of these languages: Python, JavaScript, or HTML?
\[Prompt Wrap End]

Python is known for being simple and powerful—great for beginners. JavaScript makes websites interactive. HTML isn’t a full programming language but helps structure web pages. There are many more, each used for specific types of projects.

## How Programming Languages Work

\[Prompt Wrap Start]
What do you think happens after you run your code?
\[Prompt Wrap End]

When you run your code, the computer follows your instructions one by one. Some languages are compiled (turned into machine code before running), while others are interpreted (read and run line by line). Either way, your code becomes actions the computer can do.
