## What Are Rational Expressions?

[Prompt Wrap Start]  
This section introduces rational expressions as fractions with variables.  
Prompt: How is (x + 2) / 5 different from a regular fraction like 2/5?  
[Prompt Wrap End]

A **rational expression** is a fraction where the numerator, denominator, or both contain variables.  
- Example: (x + 2) / 5  
- Example: (3x – 4) / (x + 1)  

They extend what we know about fractions into algebra. Rational expressions help us describe ratios, rates, and relationships that involve unknowns.

## Simplifying Rational Expressions

[Prompt Wrap Start]  
This section shows how to reduce rational expressions like fractions.  
Prompt: How would you simplify (6x) / (3x)?  
[Prompt Wrap End]

Just like with fractions, we can simplify rational expressions by dividing common factors:  
- (6x) / (3x) = 2 (as long as x ≠ 0).  
The key rule: we can only cancel factors, not terms connected by addition or subtraction.

## Restrictions on the Denominator

[Prompt Wrap Start]  
This section explains why some values aren’t allowed.  
Prompt: Why can’t the denominator of a fraction equal zero?  
[Prompt Wrap End]

In a rational expression, the denominator cannot equal zero.  
- Example: (x + 2) / (x – 3) is undefined when x = 3.  
When simplifying or solving, always check for values that make the denominator zero—these are restrictions.

## Comparing Rational Expressions to Fractions

[Prompt Wrap Start]  
This section builds intuition by connecting to prior knowledge.  
Prompt: How are rational expressions like the fractions you learned earlier?  
[Prompt Wrap End]

- Both involve numerators and denominators.  
- Both can be simplified by dividing out common factors.  
- Both can be added, subtracted, multiplied, and divided (with rules).  

The difference: rational expressions use variables, so they represent many possible values at once.

[Prompt Wrap Start]  
This section connects rational expressions to real-world contexts.  
Prompt: Where might you see a ratio or fraction with variables in real life?  
[Prompt Wrap End]
