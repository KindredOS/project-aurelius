## Adding and Subtracting Rational Expressions

[Prompt Wrap Start]  
This section explains how to combine rational expressions.  
Prompt: How do you add 1/2 + 1/3, and how is that like adding (x/2) + (x/3)?  
[Prompt Wrap End]

To add or subtract rational expressions, we need a **common denominator**.  
- Example: (x/2) + (x/3)  
  - Common denominator = 6  
  - (3x/6) + (2x/6) = 5x/6  

The same rule from fractions applies: align denominators, then combine numerators.

## Multiplying Rational Expressions

[Prompt Wrap Start]  
This section introduces multiplication with rational expressions.  
Prompt: How would you simplify (2x/3) × (9/4x)?  
[Prompt Wrap End]

To multiply rational expressions:  
1. Multiply numerators.  
2. Multiply denominators.  
3. Simplify by canceling common factors.  

Example: (2x/3) × (9/4x) = (18x) / (12x) = 3/2 (x ≠ 0).

## Dividing Rational Expressions

[Prompt Wrap Start]  
This section shows how to divide rational expressions.  
Prompt: What do you do first when dividing fractions like (3/4) ÷ (2/5)?  
[Prompt Wrap End]

To divide rational expressions, multiply by the reciprocal:  
- Example: (3x/4) ÷ (2/5) = (3x/4) × (5/2) = 15x/8.  

Always check for restrictions where denominators equal zero.

## Simplifying Complex Rational Expressions

[Prompt Wrap Start]  
This section explains how to handle “fractions within fractions.”  
Prompt: How would you simplify ( (x/2) / (3/4) )?  
[Prompt Wrap End]

A **complex rational expression** has fractions in the numerator or denominator.  
- Simplify by dividing: (x/2) ÷ (3/4) = (x/2) × (4/3) = 2x/3.  
The process is the same: multiply by the reciprocal and reduce.
