## What Is a Limit?

[Prompt Wrap Start]  
This section introduces limits as approaching a value.  
Prompt: If you get closer and closer to a wall but never touch it, where are you heading?  
[Prompt Wrap End]

A **limit** describes what value a function approaches as the input gets closer to a certain number.  
- Example: As x → 2 in f(x) = x + 3, the limit is 5.  
- Example: As x → 0 in f(x) = 1/x, the function grows without bound.  

Limits help us analyze behavior near a point, even if the function isn’t defined there.

## Left-Hand and Right-Hand Limits

[Prompt Wrap Start]  
This section explains limits from different directions.  
Prompt: Why might approaching a number from the left be different from the right?  
[Prompt Wrap End]

- **Left-hand limit**: approach the value from smaller x-values.  
- **Right-hand limit**: approach from larger x-values.  

If both sides agree, the limit exists. If not, the limit does not exist.

## What Is Continuity?

[Prompt Wrap Start]  
This section introduces continuity as smoothness in graphs.  
Prompt: What does it mean if you can draw a graph without lifting your pencil?  
[Prompt Wrap End]

A function is **continuous** if its graph has no breaks, jumps, or holes.  
- Example: f(x) = x² is continuous everywhere.  
- Example: f(x) = 1/x is not continuous at x = 0.  

Continuity ensures a function behaves predictably.

## Discontinuities

[Prompt Wrap Start]  
This section explains types of discontinuities.  
Prompt: What happens to the graph of 1/x at x = 0?  
[Prompt Wrap End]

- **Removable discontinuity**: a hole in the graph (like (x² – 1)/(x – 1)).  
- **Jump discontinuity**: the graph jumps between values.  
- **Infinite discontinuity**: the function heads toward infinity.  

Identifying discontinuities shows where a function fails to be continuous.

## Why Limits Matter

[Prompt Wrap Start]  
This section connects limits to calculus.  
Prompt: How can limits help us describe change at an exact point?  
[Prompt Wrap End]

Limits let us define:  
- **Derivatives**: rate of change at a point.  
- **Integrals**: accumulation of values.  

They form the foundation of calculus, turning the idea of “approaching” into precise math.
