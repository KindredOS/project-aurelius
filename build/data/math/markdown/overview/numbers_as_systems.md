## What Are Number Systems?

\[Prompt Wrap Start]
This section introduces number systems as structured ways of organizing numbers. Prompt: What different types of numbers have you used in math class?
\[Prompt Wrap End]

A number system is a set of rules for how we write and use numbers. The most common one is the base-10 system, which uses digits 0 through 9. But there are many others, like binary (used in computers) or Roman numerals. These systems help us count, calculate, and solve problems.

## The Base-10 System

\[Prompt Wrap Start]
This section explains our most commonly used number system. Prompt: What does each place value in a number mean?
\[Prompt Wrap End]

Base-10 means each place in a number is 10 times the value of the place to its right. The number 352 means 3 hundreds, 5 tens, and 2 ones. This system helps us understand place value and do operations like addition and subtraction.

## Whole Numbers and Beyond

\[Prompt Wrap Start]
This section looks at different types of numbers. Prompt: When do you use whole numbers, fractions, or decimals?
\[Prompt Wrap End]

We start with whole numbers, then expand to integers (which include negatives), fractions, decimals, and irrational numbers like π (pi). Each number type serves a purpose—for counting, measuring, or calculating. Together, they form a system for solving all kinds of problems.

## Even and Odd Numbers

\[Prompt Wrap Start]
This section focuses on patterns in number types. Prompt: What happens when you add two even numbers? Two odd ones?
\[Prompt Wrap End]

Even numbers end in 0, 2, 4, 6, or 8. Odd numbers end in 1, 3, 5, 7, or 9. These patterns help us make predictions and spot properties. For example, even + even = even, but odd + odd = even too!

## Prime and Composite Numbers

\[Prompt Wrap Start]
This section explores how numbers can be broken down into factors. Prompt: Why do we call prime numbers "building blocks"?
\[Prompt Wrap End]

Prime numbers have only two factors: 1 and themselves. Composite numbers have more than two factors. Every number is made by multiplying primes, which is why they’re called the building blocks of math.

## Comparing Number Systems

\[Prompt Wrap Start]
This section invites students to think beyond base-10. Prompt: How might a computer or ancient civilization use a different number system?
\[Prompt Wrap End]

Computers use binary (0s and 1s), while ancient civilizations used Roman numerals or base-60. Each system has strengths and weaknesses. Learning about them helps us see how math adapts to different needs.
