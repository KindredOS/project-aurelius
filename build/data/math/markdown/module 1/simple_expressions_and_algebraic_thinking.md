## What Are Simple Expressions?

[Prompt Wrap Start]  
This section introduces expressions as a way to write math ideas.  
Prompt: How can we show “five more than a number” using symbols instead of words?  
[Prompt Wrap End]

A **mathematical expression** is a phrase made of numbers, operations, and sometimes variables (letters that stand for numbers). Unlike a sentence, it doesn’t have an equal sign. For example, `x + 5` means “five more than a number.” Learning expressions is the first step toward algebraic thinking.

## Variables as Unknowns

[Prompt Wrap Start]  
This section explains what variables mean.  
Prompt: Why do you think we use letters like x or y in math?  
[Prompt Wrap End]

A **variable** is a letter that stands for an unknown number. In `2x + 3`, the “x” could be any number. Variables let us describe rules, patterns, and problems in a simple way. They are like placeholders waiting for a value.

## Writing Expressions From Words

[Prompt Wrap Start]  
This section helps students practice turning sentences into math.  
Prompt: How would you write “twice a number plus 4” as an expression?  
[Prompt Wrap End]

Translating words into symbols is a core part of algebraic thinking.  
- “Twice a number plus 4” becomes `2x + 4`.  
- “A number minus 7” becomes `x – 7`.  
This skill helps us solve real-world problems more easily.

## Evaluating Expressions

[Prompt Wrap Start]  
This section shows how to work with expressions when the variable is known.  
Prompt: If x = 3, what is the value of 2x + 5?  
[Prompt Wrap End]

To **evaluate an expression**, replace the variable with the given number.  
- Example: If `x = 3`, then `2x + 5 = 2(3) + 5 = 11`.  
Evaluating expressions helps us connect abstract symbols to concrete answers.

## Algebraic Thinking in Everyday Life

[Prompt Wrap Start]  
This section connects algebra to real-world situations.  
Prompt: Can you think of a time when you solved a problem by figuring out an unknown?  
[Prompt Wrap End]

Algebra is not just for the classroom—it shows up in daily life.  
- Figuring out how many more points you need to win a game.  
- Planning how much money you need to save for a goal.  
- Splitting a bill evenly among friends.  

Algebraic thinking helps us find unknowns and make decisions.
