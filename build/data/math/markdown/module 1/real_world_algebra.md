## What Is Algebra?

\[Prompt Wrap Start]
This section introduces the concept of algebra. Prompt: Why might we use letters instead of numbers in some math problems?
\[Prompt Wrap End]

Algebra is a way to solve problems when we don’t yet know all the numbers. Letters like x or y stand in for unknown values. It’s like a puzzle where the clues help us figure out the missing piece.

This section teaches how to translate words into algebraic expressions. Prompt: How can you turn a sentence like "3 more than a number" into math?
\[Prompt Wrap End]

Writing expressions is like turning language into math. For example, "3 more than a number" becomes x + 3. These expressions help us represent real-world situations using symbols.

## Solving Equations

\[Prompt Wrap Start]
This section introduces solving one-step algebraic equations. Prompt: What does it mean to "solve" an equation?
\[Prompt Wrap End]

Solving an equation means finding the value of the unknown that makes the equation true. If x + 5 = 9, then x must be 4. You’re working backward to find the missing number.
