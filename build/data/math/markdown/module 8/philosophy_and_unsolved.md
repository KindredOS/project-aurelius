### What Is the Philosophy of Mathematics?

[Prompt Wrap Start]  
This section introduces philosophy as asking deep questions about math.

[Prompt Wrap End]

The **philosophy of mathematics** explores what math really is.  
- Is it a human creation, like language?  
- Or is it universal truth waiting to be found?  

These questions shape how we think about numbers, proofs, and reality itself.

### Different Views of Math

[Prompt Wrap Start]  
This section introduces major philosophical perspectives.  
Prompt: How might math look different if it’s invented versus discovered?  
[Prompt Wrap End]

- **Platonism**: math exists independently, we “discover” it.  
- **Formalism**: math is a set of rules and symbols we create.  
- **Constructivism**: math only exists when we can build or prove it.  

Each view offers a different way to see what math means.

### Limits of Mathematics

[Prompt Wrap Start]  
This section explains Gödel’s Incompleteness Theorems.  
Prompt: Can every true statement in math be proven?  
[Prompt Wrap End]

Gödel showed that in any complete system, there are true statements that cannot be proven within that system. This means math, while powerful, has boundaries.
