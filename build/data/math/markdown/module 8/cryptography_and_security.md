## Cryptography and Mathematical Security

---

### What Is Cryptography?

[Prompt Wrap Start]  
This section introduces cryptography as the art of secure communication.  
Prompt: How can two people share a secret message without anyone else understanding it?  
[Prompt Wrap End]

**Cryptography** uses math to protect information.  
- Messages are encoded (encrypted) so only authorized people can read them.  
- Decoding (decryption) requires special keys.  

It’s the foundation of privacy in the digital age.

### Classical Ciphers

[Prompt Wrap Start]  
This section explains early methods of secret writing.  
Prompt: How could shifting each letter by 3 places in the alphabet hide a message?  
[Prompt Wrap End]

- **Caesar cipher**: shift letters by a fixed number.  
- **Substitution cipher**: replace each symbol with another.  
- **Transposition cipher**: rearrange order of letters.  

These simple systems are fun but easy to break.

### Modern Encryption

[Prompt Wrap Start]  
This section introduces advanced cryptography.  
Prompt: Why might today’s digital security rely on very large numbers?  
[Prompt Wrap End]

Modern cryptography uses complex math:  
- **RSA encryption**: based on factoring very large numbers.  
- **Elliptic curve cryptography**: uses properties of curves for secure keys.  
- **Hashing**: turns data into fixed codes, used in passwords.  

Security comes from problems that are hard to solve quickly.

### Keys and Public/Private Systems

[Prompt Wrap Start]  
This section explains how people share information securely.  
Prompt: How can you send a message securely to someone you’ve never met?  
[Prompt Wrap End]

- **Public key**: shared with everyone, used to lock (encrypt).  
- **Private key**: kept secret, used to unlock (decrypt).  
This system allows safe communication even across open networks.
